検証研究の協力に関する同意書（利用条件）

サービス名：処方箋ヘルパー　薬局受付・在庫チェック（以下「本サービス」）

運営：株式会社Priamos（以下「運営」）

下記の薬局（以下「協力薬局」）は、本サービスのお試し利用（以下「検証研究」）に協力するにあたり、次の条件に同意します。

第1条　目的

窓口で受けた処方箋の読み取りと在庫の照合（プランA）や、来局前に届く処方箋と初回アンケートの受付（プランB）が、薬局の業務と患者さんの待ち時間にどう役立つかを確かめ、本サービスを改善することを目的とします。

第2条　プラン・期間・費用

  1. 協力薬局は、プランA（窓口の処方箋チェック）、プランB（初回問診の受信箱）、プランAB（AとBの両方）のいずれかを、受付画面で選びます。期間中もいつでも変更できます。ただし、プランAに変更するときは、まだ完了していない受付を先に完了してください。
  2. 期間は、運営と協力薬局が相談して決めます。双方の合意により、延長・短縮できます。
  3. 検証研究の期間中、協力薬局は本サービスを無料で利用できます。
  4. 有料化の際は、運営が料金と条件を改めてご案内します。協力薬局がお申し込みになった場合に限り有料の契約に移ります。自動的に有料になることはありません。

第3条　本サービスでできること

どのプランも共通

  1. 協力薬局は、受付用のブラウザで https://rxhelper.jp/pharmacy にログインして使います。初めてログインしたときにプランを選び、画面には、選んだプランの機能だけが表示されます。プランを選ぶまでは、患者さんからの送信は受け付けません。

プランA

  1. 窓口で受けた処方箋を撮影または取り込むと、AIが薬の名前と用法・日数を読み取り、出荷状況と協力薬局の在庫CSVとの照合を表示します。
  2. プランAでは、患者さんからの送信は受け付けません。

プランB

  1. 患者さんが、窓口のQRコードから会員登録なしで、処方箋の写真・初回アンケートの答え・受け取りの希望時刻を協力薬局に送れます。アンケートは外国語でも答えられ、薬局には日本語で届きます。
  2. 協力薬局は、受付用のブラウザで届いた受付を確認できます（受信箱・処方箋の写真・問診票（日本語）の印刷）。プランBでは、AIによる薬の読み取りと在庫の照合は行いません。
  3. 患者さんへの返信（準備できました／疑義照会中／○時以降にご用意）と、定型・自由入力のメッセージを送れます。メッセージは患者さんの言語に翻訳され、日本語の原文も表示されます。
  4. 「完了」を押すと、その受付のデータが削除されます。

プランAB

  1. プランAとプランBの機能を両方使えます。患者さんから届いた処方箋も、AIが薬を読み取り、在庫CSVと照合します。

第4条　役割分担

  1. 調剤・疑義照会・服薬指導などの判断は、協力薬局の薬剤師が行います。
  2. AIによる薬の読み取りと在庫の照合結果は参考情報です。必ず処方箋の原本（または写真）で確認してください。本サービスの表示は判断の補助であり、最終的な判断は協力薬局が行います。
  3. 患者さんからの写真の送信は、処方箋の原本の代わりにはなりません。お薬のお渡しの際は、通常どおり処方箋の原本を確認してください。
  4. 運営は、本サービスの提供、不具合の対応、使い方のご案内を行います。
  5. 本サービスは、レセコンのパソコンではなく、インターネットにつながる受付用の別のパソコン・タブレットでお使いください。

第5条　アカウントの管理

  1. 運営は、協力薬局ごとにアカウントと薬局コードを発行します。プランB・ABを選んだ場合は、窓口に置くQRコードのチラシを受付画面から印刷できます。
  2. パスワードは、運営がお送りする「初回設定のリンク」（14日間有効・1回限り）から、協力薬局が決めます。運営はパスワードを知りません。
  3. ログインは協力薬局の職員に限り、端末には画面ロックをかけるなど、第三者に見られないよう管理してください。
  4. パスワードを忘れた場合は、ログイン画面の「パスワードを忘れた方」から設定し直せます。パスワードが漏れたおそれがある場合は、設定し直したうえで、運営にご連絡ください。パスワードを設定し直すと、ほかの端末のログインは終了します。

第6条　データの扱い

プランA（窓口の処方箋チェック）

  1. 送る内容：窓口で撮影または取り込んだ処方箋の画像です。要配慮個人情報を含みます。薬の読み取りのため、AI（Anthropic社、米国）に送ります。
  2. 保存しない：運営のサーバーには、処方箋の画像も読み取り結果も保存しません。読み取り結果は、協力薬局の画面に表示するだけです。
  3. 患者さんへのお知らせと確認：協力薬局は、運営が用意する掲示「処方箋の確認に、AIを使っています」を窓口に掲げ、処方箋の画像を本サービスに取り込む前に、AIで読み取ってよいかを患者さんに口頭で確認します。了承を得た処方箋だけを取り込みます。了承を得られない場合は、通常どおり確認します。

プランB・AB（患者さんからの送信）

  1. 届く内容：処方箋の写真、初回アンケートの答え、受け取りの希望時刻、（患者さんが入力した場合）メールアドレス。これらは要配慮個人情報を含みます。
  2. 患者さんの同意：患者さんは送信の前に、画面上で次の内容に同意します。
    • 選んだ薬局に処方箋の写真とアンケートの答えを送ること
    • 処方箋の読み取りと自由記述の翻訳にAI（Anthropic社、米国）を使うこと（プランBでは、薬の読み取りは行いません）
    • 薬局が確認したあと自動で削除されること（確認されなくても7日で削除）
  3. 保存先：運営が利用するクラウドサービス（Cloudflare社、米国）のデータベースに、一時的に保存します。
  4. 削除：協力薬局が「完了」を押した時点で、写真・答え・メッセージ・メールアドレスを削除します。完了されなくても、送信から7日で自動的に削除します。
  5. メール通知：患者さんへのお知らせメールには「薬局から返信がありました」とリンクだけを書き、薬の名前などは書きません。

どのプランも共通

  1. 残る記録：検証研究の集計のため、受付の時刻の記録（届いた・開いた・返信した・完了した）、窓口で照合した時刻、患者さんの言語、薬の数だけを残します。氏名・処方の内容など、個人を特定できる情報は含みません。
  2. 在庫CSV：協力薬局のブラウザの中だけで読み込み、運営のサーバーには送りません。読み込んだ内容はそのブラウザに保存され、「このブラウザから消す」で消せます。
  3. 目的外の利用の禁止：運営は、届いた内容を本サービスの提供以外に使いません。運営が受付の中身を見るのは、協力薬局から依頼された不具合の調査など、必要な場合に限ります。
  4. 協力薬局の管理：印刷した問診票は、薬局の通常の書類と同じく管理してください。患者さんの情報を本サービスの外に持ち出さないでください。

第7条　検証研究で集めるもの・結果の扱い

  1. 集めるもの：第6条9項の自動の記録、導入前の在庫確認にかかる時間の目安（聞き取り）、使いにくい点などのご意見（聞き取り・アンケート）。
  2. 結果は、本サービスの改善と、今後のご案内資料に使うことがあります。協力薬局の名前を出す場合は、事前にご了承をいただきます。個人を特定できる形では公表しません。

第8条　患者さんへのご案内（プランB・AB）

  1. 本サービスは「薬局が提供する服薬サポートのサービス」としてご案内ください。
  2. ポイント・割引・現金など、金銭的な特典は付けません。窓口の案内には、受付画面から印刷できる運営が用意したチラシをお使いください（文面を変える場合はご相談ください）。
  3. 本サービスを使うかどうかは患者さんの自由です。使わない患者さんには、通常どおりの受付で対応してください。

第9条　不具合・停止

  1. 検証研究の段階のため、不具合が起きたり、予告なく止まったりすることがあります。止まっている間は、通常の受付で対応してください。
  2. 運営は、不具合を知ったときは速やかに対応し、協力薬局にお知らせします。
  3. 個人情報の漏えいのおそれを知ったときは、運営は速やかに協力薬局に連絡し、対応を相談します。

第10条　終了

  1. 協力薬局・運営のどちらからでも、連絡によりいつでも終了できます。
  2. 終了したときは、運営はアカウントを停止し、その時点で残っている受付のデータを速やかに削除します。プランB・ABの場合、協力薬局は窓口のQRチラシを撤去してください。
  3. 第6条9項の記録（個人を特定できない数値）は、集計のために残ることがあります。
