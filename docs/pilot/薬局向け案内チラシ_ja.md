# 薬局向け案内チラシ（窓口に置く文面）

> 窓口に置く患者さん向けチラシの文面です。A4縦1枚。［　］の部分は薬局ごとに入れ替えます。
> 金銭的な特典（ポイント・割引・現金など）や「無料」を打ち出す表現は使いません（患者誘引の禁止）。

## ［薬局名］の受付サービス

# 来局前に、処方箋の写真を送れます

お薬の準備ができたら、スマートフォンの画面でお知らせします。

### 使い方

1. **QRコードを読み取る**
   スマートフォンのカメラで、下のQRコードを読み取ってください。
2. **処方箋の写真を撮って送る**
   初回アンケートは、ふだんお使いの言語で答えられます。薬局には日本語で届きます。
3. **画面でお知らせを確認する**
   「準備ができました」などのお知らせが画面に出ます。メールでのお知らせも選べます。

［ここに薬局のQRコード］
https://rxhelper.jp/send?ph=［薬局コード］

### ご確認ください

- お薬を受け取るときは、**処方箋の原本**と、**お薬手帳かマイナ保険証**をお持ちください。写真を送っただけでは、お薬はお渡しできません。
- 電子処方箋の場合は、「控え」（引換番号つき）の写真を送ってください。
- 会員登録はいりません。
- 送った内容は、薬局が受付を完了した時点で削除されます。完了されなくても、7日で自動的に削除されます。
- 処方箋の読み取りと翻訳に、AI（海外のサーバー）を使います。詳しくは送信の画面とプライバシーポリシーをご覧ください。
- 使うかどうかは自由です。これまでどおり、窓口に処方箋をお持ちいただいてもかまいません。

### 使える言語

日本語 ・ English ・ 한국어 ・ 中文 ・ Tiếng Việt ・ Bahasa Indonesia ・ Filipino ・ ภาษาไทย ・ မြန်မာ ・ नेपाली ・ Português
