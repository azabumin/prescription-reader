太い矢印は画面の移動ではなく、データが相手側に届くことを表す。届いた内容は、薬局が「完了」を押した時点で削除され、完了されなくても送信から7日で削除される。

受付の状態の移り変わり

stateDiagram-v2
  direction LR
  [*] --> new : 患者さんが送る
  new --> ready : 返信
  new --> inquiry : 返信
  new --> later : 返信（時刻を選ぶ）
  ready --> inquiry
  inquiry --> ready
  inquiry --> later
  later --> ready
  new --> done : 完了
  ready --> done : 完了
  inquiry --> done : 完了
  later --> done : 完了
  done --> [*] : 送信から7日で削除
  new --> [*] : 完了されずに7日で削除

状態ごとの表示

状態薬局の画面患者さんの画面（日本語の場合）
new未返信薬局が確認しています。
ready準備できました薬の準備ができました。
inquiry疑義照会中薬局が病院に確認しています。少し時間がかかります。
later○時以降にご用意○時から受け取れます。（17時〜20時）
done完了受付は完了しました。
（削除後）この受付は削除されましたこの受付は削除されました（7日経過または完了）。

返信・メッセージのたびに、メールを希望した患者さんにだけ「薬局から返信がありました」とリンクを送る（中身は書かない）。完了した受付には返信できない。返信済みの受付も、完了までは状態を変えられる（図は主な流れのみ）。
